# commtrain:コミュニケーション訓練用の録音分析ツール

スマホで録音した自分の話(自己紹介・経済学の説明・面接の回答など)をローカルで分析し、

1. 数値で測れる指標を自動で出す(`analyze`)
2. Claude に採点を頼むための「採点パケット」を作る(`packet`)
3. 8週間の推移を記録・比較する(`history` / `compare`)

ためのコマンドラインツールです。**音声は外部に送らず、すべてローカルで処理します。**

> 初回だけ、faster-whisper のモデル(medium など)を Hugging Face からダウンロードします。
> ダウンロードされるのはモデルだけで、音声は送信されません。2回目以降はキャッシュを使います
> (完全にオフラインで動かしたい場合は、モデル取得後に環境変数 `HF_HUB_OFFLINE=1` を設定してください)。

## 必要なもの

- Python 3.11 以上
- ffmpeg(PATH が通っていること)
- GPU は任意(CUDA が使えれば自動で使います)

## インストール

```bash
cd communication
python -m venv .venv
source .venv/bin/activate          # Windows は .venv\Scripts\activate
pip install -e .                   # または pip install -r requirements.txt
```

`pip install -e .` で `commtrain` コマンドが使えるようになります。
`pip install -r requirements.txt` の場合は `python -m commtrain ...` で実行してください。

## 使い方

### 1. 分析:`commtrain analyze`

```bash
commtrain analyze 録音/w1_自己紹介.m4a --task 自己紹介 --week 1
```

- `--task`:`自己紹介` / `経済学` / `面接` / `雑談` / `配信` / `その他`
- `--week`:0〜8
- 入力:wav / m4a / mp3(内部で 16kHz モノラルに変換)
- 出力(音声と同じフォルダ):
  - `<ファイル名>_report.md`:指標A〜Cの表、1.0秒以上の間とフィラーの前後の発言、タイムスタンプ付き文字起こし
  - `<ファイル名>_metrics.json`:すべての測定値と文字起こし(単語のタイムスタンプ付き)
- `history.csv` に1行追記します(追記したくないときは `--no-history`)

文字起こしのオプション:

| オプション | 既定 | 説明 |
|---|---|---|
| `--model` | `medium` | `large-v3` などに変更可 |
| `--device` | `auto` | `auto`(GPU があれば使う)/ `cpu` / `cuda` |
| `--compute-type` | `auto` | GPU は `float16`、CPU は `int8` |

### 2. 採点パケット:`commtrain packet`

```bash
commtrain packet 録音/w1_自己紹介.m4a           # → w1_自己紹介_packet.md
commtrain packet 録音/w1_自己紹介.m4a -o -      # 標準出力へ(macOS なら | pbcopy でコピー)
```

`analyze` 済みなら `<ファイル名>_metrics.json` を再利用するので、文字起こしをやり直しません。
未分析なら分析してから作ります(このときは履歴に追記しません。`--task` `--week` で課題と週を指定できます)。

パケットの中身(この順):

1. 課題名・週・録音の長さ
2. 指標A〜Cの要約
3. タイムスタンプ付き文字起こし
4. 採点依頼文(6要素を1〜5点で採点する依頼。文面は固定)

ファイルの中身をそのまま Claude のチャットに貼ってください。

### 3. 比較:`commtrain compare`

```bash
commtrain compare --week-a 0 --week-b 8                 # 両方の週に記録がある課題すべて
commtrain compare --week-a 0 --week-b 8 --task 自己紹介
commtrain compare --week-a 0 --week-b 8 -o 比較.md      # ファイルに保存
```

同じ課題同士を並べ、増減(Week B − Week A)の列をつけた Markdown 表を出します。
同じ週・課題に複数の記録があるときは、**最後に追記された記録**を使います。

### 4. 履歴:`commtrain history`

```bash
commtrain history
commtrain history --task 経済学
```

`history.csv` を週ごと・課題ごとに一覧表示します。

## 履歴ファイル(history.csv)

- 場所:このツールのフォルダ直下(`communication/history.csv`)。環境変数 `COMMTRAIN_HISTORY` で変更できます。
- 文字コード:UTF-8(BOM 付き。Excel でそのまま開けます)
- 列:

| 列 | 内容 |
|---|---|
| `date` | 分析日 |
| `week` / `task` / `file` | 週・課題・ファイル名 |
| `duration_sec` | 全長(秒) |
| `span_sec` | 発話区間(秒) |
| `voiced_ratio_pct` | 発声割合(%、発声時間 ÷ 発話区間) |
| `pauses_ge05` | 0.5秒以上の間(回) |
| `pauses_ge05_per_min` | 1分あたりの0.5秒以上の間 |
| `pauses_ge10` | 1.0秒以上の間(回) |
| `longest_pause_sec` | 最長の間(秒) |
| `articulation_rate` | 調音速度(モーラ/秒) |
| `overall_rate` | 全体速度(モーラ/秒) |
| `filler_count` | フィラー数(下限値) |
| `mean_sentence_chars` | 平均文長(字) |
| `semitone_range` | 半音幅(5〜95パーセンタイル) |
| `note` | 注記 |

### Week 0 の基準値

別の環境で同じ定義Aで測った値を初期データとして入れてあります(話速・フィラー・文長は未測定のため空欄)。

| 課題 | 全長 | 発声割合 | 0.5秒以上の間 | 1.0秒以上の間 | 最長の間 | 半音幅 |
|---|---|---|---|---|---|---|
| 自己紹介 | 65.1 秒 | 77 % | 11 回 | 2 回 | 2.43 秒 | 9.3 |
| 経済学 | 123.2 秒 | 80 % | 22 回 | 6 回 | 1.76 秒 | 10.7 |

基準値には発話区間の記録がないため、「1分あたりの0.5秒以上の間」は**全長で換算**しています
(自己紹介 10.14 回/分、経済学 10.71 回/分)。このツールで測った値は発話区間で割るので、
最初の発声までの無音や末尾の無音の分だけ、基準値の方がわずかに小さく出ます。回数そのもの(`pauses_ge05`)は同じ定義です。

## 指標の定義

過去の測定値と比べるため、以下の定義は変えないでください。

### A. 間と発声(音声のみから計算)

| 項目 | 定義 |
|---|---|
| 前処理 | ffmpeg で 16kHz モノラルに変換 |
| フレーム | RMS をフレーム長 400 サンプル(25ms)、ホップ 160 サンプル(10ms)で計算。フレームは中心揃え(両端を 200 サンプルのゼロで埋める。librosa の `center=True` と同じ)。フレーム i の時刻は i × 10ms |
| 音量 | dB = 20·log10(RMS + 1e-9) |
| 閾値 | 雑音(dB の10パーセンタイル)+ 0.35 ×(95パーセンタイル − 雑音)。閾値を**超える**フレームを発声とする |
| 平滑化 | ① 150ms 未満の無音を発声に埋める(録音の先頭・末尾に接する無音は除く) ② その後、80ms 未満の発声を無音にする |
| 全長 | 録音の長さ(秒) |
| 最初の発声までの秒数 | 最初の発声フレームの時刻 |
| 発話区間 | 最初の発声の開始〜最後の発声の終了 |
| 発声時間 | 発声フレーム数 × 10ms |
| 発声割合 | 発声時間 ÷ 発話区間(参考として 発声時間 ÷ 全長 もレポートに表示) |
| 発声のかたまり | 連続した発声。数・平均の長さ・最長 |
| 間 | 発話区間内の無音のうち 0.15秒以上のもの。回数・中央値・0.5秒以上の回数・1.0秒以上の回数・最長、1.0秒以上の間は位置(開始秒)と長さ |
| 前半/後半 | 発話区間の中点で分割。間の中央の時刻がどちらにあるかで振り分け、それぞれの間の回数と 0.5秒以上の回数 |
| 10秒ごとの発声率 | 録音の先頭から 10 秒ずつ区切った区間ごとの、発声フレームの割合(%)。最後の区間は残りの長さで割る |
| 1分あたりの間の回数 | 間の回数 ÷ 発話区間(分)。0.5秒以上・1.0秒以上についても同様 |

注意:25ms の窓が音の端に少しでもかかったフレームは発声と判定されるため、測定される間は実際の無音より最大で約 0.025 秒短くなります(定義上の性質で、比較には影響しません)。

### B. 声の高さ

| 項目 | 定義 |
|---|---|
| F0 推定 | `librosa.pyin`、fmin 70Hz、fmax 400Hz、frame_length 1024、hop 160 |
| F0 中央値 | 有声と判定されたフレームの F0 の中央値(Hz) |
| 半音値 | 12·log2(F0 ÷ 中央値) |
| 半音幅 | 半音値の 95パーセンタイル − 5パーセンタイル |
| 半音の標準偏差 | 半音値の標準偏差 |

音量のばらつきは、スマホのノイズ抑制で歪むため指標に含めていません。

### C. 文字起こしから計算

**文字起こし**:faster-whisper、`language="ja"`、`word_timestamps=True`、`vad_filter=False`、`beam_size=5`。
フィラーを残させるため、`initial_prompt` に
「えー、あのー、えっと、今日はですね、まあ、なんか、うーん、そのー、話してみます。」を入れています。

**モーラ数**

- fugashi + unidic-lite で形態素に分け、各語の読み(カタカナ。発音形 → 読み形 → かなの表層形の順に採用)からモーラを数える
- 小書きの ャ ュ ョ ァ ィ ゥ ェ ォ(と ヮ)は前の字と合わせて1モーラ。ッ・ー・ン は1モーラ
  - 例:きょうは = 3、がっこう = 4、コーヒー = 4
- 読みが取れない語(算用数字・英字など)は数えず、レポートに「読みを取得できずモーラ数に含めていない語」として列挙する
- フィラーも発話なのでモーラ数に含める

**話速**

| 項目 | 定義 |
|---|---|
| 調音速度 | モーラ数 ÷ 発声時間(モーラ/秒) |
| 全体速度 | モーラ数 ÷ 発話区間(モーラ/秒) |

**フィラー**(数は**下限値**。Whisper はフィラーを省略しがちなため)

対象:えー / えーと / えっと / あの / あのー / その / そのー / まあ / なんか / うーん / うん(文頭のみ)

照合の規則:

- ひらがなに揃えて照合し、長い形を優先する(「えーと」は「えー」より先、「あのー」は「あの」より先)
- 表記ゆれ:伸ばし棒の重なり(えーーと)、「えーっと」「ええと」は「えーと」、「まぁ」「まー」は「まあ」として数える
- 形態素の境界から始まり、境界で終わるものだけを数える(「マーケット」の「マー」などを除く)
- 「あの」「その」「なんか」「うん」は、直後が読点・句点・空白・文末・別のフィラーのときだけ数える(「あの人」「その後」などの指示詞を除くため。そのため「なんかすごい」のように読点のないフィラーは数えない)
- 「うん」は文頭(録音の最初、句点・疑問符・感嘆符・セグメント境界の直後)のみ
- 位置は、そのフィラーを含む単語の開始時刻(秒)

**文**

| 項目 | 定義 |
|---|---|
| 区切り | 句点(。)・疑問符(? ?)・Whisper のセグメント境界 |
| 文字数 | 空白・句読点・括弧などの記号を除いた文字数 |
| 出力 | 文の数、平均文字数、最長の文(文字数と本文) |
| 冒頭の一文 | 最初の文を本文のまま表示(結論から始まっているかは人が判断する。自動判定はしない) |

### レポートに書かないこと

結論が先か、構成の良し悪し、言い間違いなど、自動で判定できないことは書きません。数値と事実だけです。
それらの評価は採点パケットを使って Claude に依頼してください。

## テスト

```bash
pip install -e ".[test]"
pytest
```

- `tests/test_pauses.py`:既知の長さの無音を挟んだ合成音声(サイン波)で、間の回数・長さ・位置、平滑化、前半/後半、10秒ごとの発声率を確認
- `tests/test_mora.py`:モーラ数の数え方(きょうは=3、がっこう=4、コーヒー=4 など)
- `tests/test_text.py`:フィラー・文の区切り・前後の発言・10秒区切りの文字起こし
- `tests/test_cli.py`:analyze → packet → compare → history の通し動作(文字起こしはスタブ。ffmpeg と librosa は実物を使用)
- `tests/test_history.py`:履歴の追記・比較、Week 0 基準値

## ファイル構成

```
commtrain/
  cli.py           コマンド
  audio.py         ffmpeg による読み込み(16kHz モノラル)
  pauses.py        指標A:間と発声
  pitch.py         指標B:声の高さ
  transcribe.py    faster-whisper による文字起こし
  text_metrics.py  指標C:モーラ・話速・フィラー・文
  report.py        report.md と採点パケット
  history.py       history.csv の追記・一覧・比較
history.csv        履歴(Week 0 の基準値入り)
```
